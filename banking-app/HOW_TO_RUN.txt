🎯 METHOD 1: DOUBLE-CLICK THE FILE (EASIEST!)

   1. Find the file: START.bat
   2. Double-click it
   3. A black window will open (server starting)
   4. Wait for "Server is running!" message
   5. Open your browser
   6. Go to: http://localhost:3000
   7. Login with: demo@bcc.kz / demo123

❌ "Port 3000 is already in use"
   Solution: Close any other programs using port 3000
   Or edit server-sqlite.js line 10 to use different port

❌ "Cannot access from mobile"
   Solution:
   • Make sure phone and PC on same WiFi
   • Check Windows Firewall
   • Allow Node.js through firewall

❌ "Node is not recognized"
   Solution:
   • Node.js not installed
   • Download from: https://nodejs.org/
   • Install and restart computer

❌ Browser shows blank page
   Solution:
   • Make sure server is running (check black window)
   • Try refreshing the page (F5)
   • Check if you're using http:// not https://
