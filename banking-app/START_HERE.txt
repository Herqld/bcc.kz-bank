════════════════════════════════════════════════════════════════════════
                    🛠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

❌ "npm is not recognized"
   → Node.js not installed or not in PATH
   → Install Node.js and restart computer

❌ "Cannot connect to database"
   → MySQL not running or wrong password
   → Check MySQL Workbench connection
   → Edit server.js password (line 26)

❌ "Port 3000 already in use"
   → Another app using port 3000
   → Change PORT in server.js to 3001

❌ "Cannot access from mobile"
   → Check same WiFi network
   → Check Windows Firewall settings
   → Allow Node.js through firewall

❌ "Module not found"
   → Dependencies not installed
   → Run: npm install

                    🎓 HOW IT WORKS
════════════════════════════════════════════════════════════════════════

1. User opens browser → Requests HTML page
2. Browser loads HTML/CSS/JS → Shows interface
3. User clicks button → JavaScript sends request to server
4. Server receives request → Processes logic
5. Server queries database → Gets/updates data
6. Server sends response → Success or error
7. JavaScript updates page → Shows result

Frontend (Browser):
  • HTML - Structure (buttons, forms)
  • CSS - Styling (colors, layout)
  • JavaScript - Interactions (clicks, requests)

Backend (Server):
  • Node.js - Runtime environment
  • Express - Web server framework
  • Handles API requests
  • Processes business logic

Database (MySQL):
  • users - Account information
  • accounts - Bank cards/accounts
  • transactions - All money movements
  • deposits - Deposit accounts
