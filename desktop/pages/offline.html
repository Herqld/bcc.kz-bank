CODDY 2.2

Cannot reach the bank server.

Checking…

Server address · Адрес сервера · Сервер мекенжайы

Examples: http://localhost:3000 (server on this PC), http://192.168.0.7:3000 (another PC on your Wi-Fi), https://your-tunnel.example.com (a public tunnel / cloud).

English

  1. If the server runs on THIS computer: double-click banking-app/START.bat (or install Node.js 20+ so this app starts it by itself). Then press Retry.
  2. If the server is on another computer or in the cloud, type its address above and press Save & connect. The server must be running there.
  3. Tip: the server prints its reachable addresses when it starts (e.g. http://192.168.0.7:3000). Use one of those, not localhost, from another PC.

Русский

  1. Если сервер на ЭТОМ компьютере: запустите banking-app/START.bat (или установите Node.js 20+, чтобы приложение запускало сервер само). Затем нажмите «Повторить».
  2. Если сервер на другом компьютере или в облаке — введите его адрес выше и нажмите «Сохранить и подключиться». Сервер там должен быть запущен.
  3. Подсказка: при запуске сервер печатает свои адреса (например http://192.168.0.7:3000). С другого ПК используйте их, а не localhost.

Қазақша

  1. Сервер ОСЫ компьютерде болса: banking-app/START.bat іске қосыңыз (немесе қосымша оны өзі іске қосуы үшін Node.js 20+ орнатыңыз). Содан кейін «Қайталау» басыңыз.
  2. Сервер басқа компьютерде немесе бұлтта болса — мекенжайын жоғарыға енгізіп «Сақтау және қосылу» басыңыз. Сервер сол жерде іске қосылған болуы тиіс.
  3. Кеңес: сервер іске қосылғанда өз мекенжайларын шығарады (мысалы http://192.168.0.7:3000). Басқа компьютерден localhost емес, соларды пайдаланыңыз.
